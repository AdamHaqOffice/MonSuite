# Abatement Link Projects handoff

MonSuite V41 removes the local Projects / ICRA CSV reporting feature.

The project monitoring/reporting concept should be implemented in Abatement Link instead, with:

- live project dashboards
- PPM4/RPM/AGIM3 project assignment
- project requirements
- excursion detection
- alert acknowledgement
- escalation
- corrective actions
- user tracking
- daily reports
- final reports
- audit history
- report reproducibility

MonSuite should link users to Abatement Link Projects when those features exist.
