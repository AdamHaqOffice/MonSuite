# MonSuite V42 — Sales Guide and Planner Value Tools

## Purpose
V42 keeps MonSuite focused on sales/support value instead of turning it into a second live monitoring platform.

Projects / ICRA live reports remain positioned for Abatement Link. MonSuite now helps sales explain the value, compare market expectations, guide customers through product/package selection, and generate a practical handoff report.

## Main changes

### Applications & Sales Guide
The former Pressure Guide route remains `/pressure-monitoring`, but the nav label is now **Sales Guide** and the Hub card is now **Applications & Sales Guide**.

Added:
- Abatement Link Projects positioning
- competitor-backed battlecards
- report gallery
- labor-savings / ROI calculator
- use-case sales playbooks
- market-proof infographic asset at `/sales-guides/market-proof-cutout.svg`
- existing pressure basics, ACH calculator, troubleshooting, glossary, and external references retained

### Airflow Planner improvements
Added:
- real-job starter presets
- monitoring package recommendation logic
- sales fit notes
- questions to confirm before final quote
- stronger customer handoff report text
- monitoring package summary in live planner cards and report strip

### AbateBot
Updated `src/data/chatbotBrain.json` and the public text mirror with V42 entries for the consolidated Sales Guide, Abatement Link Projects positioning, and the improved Airflow Planner workflow.

## Important product positioning
- MonSuite should help sales/support explain, plan, and hand off recommendations.
- Abatement Link should own live project monitoring, alerts, acknowledgements, user tracking, reports, and audit history.
- Airflow and ACH estimates do not prove pressure. Pressure must be verified with a calibrated monitor when pressure is required or claimed.
- Competitor comparisons are internal sales guidance, not legal/public claims.
